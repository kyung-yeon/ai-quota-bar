AiQuotaBar 설치 안내
macOS 13 이상 · Apple Silicon 및 Intel 지원

1. AiQuotaBar.app을 Applications 바로가기로 드래그합니다.
2. 이 디스크 이미지를 추출합니다.
3. 응용 프로그램에서 AiQuotaBar를 실행합니다. Dock 대신 메뉴 막대에 표시됩니다.
4. Codex CLI 또는 Claude Code를 설치하고 로그인한 뒤 지금 새로고침을 누릅니다.

AiQuotaBar 자체 설치에는 Swift 컴파일러, Python, Node.js가 필요하지 않습니다.
각 서비스의 CLI에는 별도의 설치 요구 사항이 있습니다.

이미 AiQuotaBar를 사용 중이라면
실행 중인 앱을 먼저 종료한 뒤 현재 설치된 폴더의 앱을 교체하세요.
소스 설치는 보통 ~/Applications에 있습니다. 기존 로그인 자동 실행을 유지하려면
그 위치의 앱을 교체하고 /Applications에 두 번째 사본을 만들지 마세요.

로그인 시 실행 (선택)
시스템 설정 > 일반 > 로그인 항목(또는 로그인 항목 및 확장 프로그램)의
로그인 시 열기에 AiQuotaBar를 추가하세요. 드래그 설치는 자동 실행 항목을
자동으로 등록하지 않습니다.

처음 실행할 때

확인하세요. 이 배포본을 신뢰한다면 Apple의 안내에 따라 실행할 수 있습니다.

표시될 수 있습니다. Gatekeeper를 시스템 전체에서 비활성화하지 마세요.
