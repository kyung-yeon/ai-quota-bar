AiQuotaBar 커맨드 설치 안내
macOS 13 이상 · Apple Silicon 및 Intel 지원

Xcode Command Line Tools가 없다면 설치하고 완료될 때까지 기다립니다.
  xcode-select --install

소스를 내려받고 설치합니다.
  git clone https://github.com/kyung-yeon/ai-quota-bar.git
  cd ai-quota-bar
  make install

빌드·테스트·설치·실행과 로그인 시 자동 실행 등록을 한 번에 수행합니다.
신규 설치는 ~/Applications/AiQuotaBar.app을 사용하며, ~/Applications 또는
/Applications에 기존 앱이 있으면 그 위치에서 교체합니다.
두 폴더의 중복 사본과 빌드용 앱은 정리하고 앱 백업 사본은 남기지 않습니다.

메뉴 막대의 아이콘을 클릭해 사용량을 확인합니다. Codex CLI 또는 Claude Code를
설치하고 로그인한 뒤 지금 새로고침을 누릅니다.

기존 소스 폴더에서 업데이트합니다.
  git pull --ff-only
  make install
