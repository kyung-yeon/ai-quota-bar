AiQuotaBar — Command-line installation
macOS 13 or later · Apple Silicon and Intel

Install Xcode Command Line Tools if needed, and wait for it to finish:
  xcode-select --install

Download and install:
  git clone https://github.com/kyung-yeon/ai-quota-bar.git
  cd ai-quota-bar
  make install

The command builds, tests, installs, and starts the app. It also configures
launch at login. A new installation uses ~/Applications/AiQuotaBar.app;
an existing copy in ~/Applications or /Applications is replaced in place.
Duplicate copies in these folders and the temporary build bundle are removed.
No persistent app backups are created.

Its icons appear in the menu bar. Install and sign in to Codex CLI and/or
Claude Code, then choose Refresh now.

Update from the source folder:
  git pull --ff-only
  make install

Full setup and uninstall instructions:
https://github.com/kyung-yeon/ai-quota-bar/blob/main/README.md
