# 로컬 API 환산 비용 추정

사용량 팝업의 **로컬 API 환산 추정**에서 USD 합계와 클라이언트·서비스·모델별 내역을 확인합니다. 이 Mac에 남아 있는 지원 기록 전체를 대상으로 하며, 특정 월이나 구독 한도 기간의 금액이 아닙니다. **실제 청구액·구독료가 아니며 사용한도 비율을 돈으로 환산하지 않습니다.** `+ ?`는 확인된 항목만 더한 소계라는 뜻입니다. 가격·모델·요청 경계가 없는 기록은 **추정 불가**로 남기고 0달러로 처리하지 않습니다.

앱 시작·잠자기 해제·수동 새로고침 및 5분 간격으로 백그라운드에서 집계합니다. 기존 기록 조회에는 해당 CLI의 설치·로그인이 필요하지 않습니다.

## 지원 기록

- **Codex:** `$CODEX_HOME` 또는 `~/.codex` 아래 `sessions`, `archived_sessions`의 JSONL. 모델과 토큰 사용 이벤트를 읽고 반복 누계·복사된 이벤트를 중복 집계하지 않습니다. 캐시 입력과 추론 출력은 이미 포함된 토큰을 다시 더하지 않습니다. 최초 누계만 있는 기록은 기준값으로 두고, 이후 요청 경계가 없는 누계 차이는 비용을 추정하지 않습니다.
- **Claude Code:** `$CLAUDE_CONFIG_DIR` 또는 `~/.claude` 아래 `projects`, `transcripts`의 JSONL. assistant 사용량의 입력·출력·캐시 읽기·쓰기와 1시간 캐시 쓰기를 읽습니다. 같은 메시지의 스트리밍 갱신은 최댓값으로 합칩니다.
- **OpenCode:** `$XDG_DATA_HOME/opencode` 또는 `~/.local/share/opencode`의 `opencode*.db`. `OPENCODE_DB`가 있으면 그 파일을 사용합니다. `message`, `session_message`, `session`, `session_v2`의 사용량 필드만 읽기 전용 SQL로 조회합니다. 양수로 기록된 USD 비용을 우선 사용하며, 없으면 지원하는 정확한 OpenAI·Anthropic 모델만 정가로 계산합니다.

**DeepSeek 등 다른 서비스도 OpenCode에 서비스·모델 정보가 기록되면 표시합니다.** 양수의 기록 비용이 없으면 현재는 추정 불가입니다. [DeepSeek 공식 요금](https://api-docs.deepseek.com/quick_start/pricing)은 모델 버전·혼잡 시간·공휴일 등에 따라 달라지므로 다른 모델의 가격을 대신 적용하지 않습니다. 기록된 0만으로 무료 사용이라고 판단하지 않습니다.

OpenCode 세션 누계는 모델을 바꿔 사용했을 수 있으므로 메시지별 기록 비용과 정확히 일치할 때만 모델별로 나눕니다. 그 외에는 **mixed/unspecified · session totals**로 표시합니다. 마이그레이션된 누계는 더하지 않고 최댓값을 쓰며, DB 간 같은 세션은 기본 `opencode.db`를 우선합니다. 옛 OpenCode JSON 저장 형식, 원격 컴퓨터, 웹 대화, 다른 클라이언트, 앱 환경에 전달되지 않은 별도 경로는 포함하지 않습니다. 셸에만 설정한 환경변수는 로그인 시 실행되는 앱에 자동 전달되지 않습니다.

## 가격·정확도

가격표는 **2026-11-12** 기준 [OpenAI 요금](https://developers.openai.com/api/docs/pricing), [GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4), [GPT-5.1-Codex](https://developers.openai.com/api/docs/models/gpt-5.1-codex), [Anthropic 요금](https://platform.claude.com/docs/en/about-claude/pricing)을 확인했습니다. 지원하는 정확한 모델 ID의 표준 텍스트 API 정가를 사용하며 앱 업데이트로 갱신합니다. 날짜가 붙은 Claude 모델은 기본 모델 가격을 적용합니다. 알려지지 않은 별칭에는 임의 가격을 붙이지 않습니다.

입력·출력·캐시 읽기 및 Claude의 5분/1시간 캐시 쓰기를 구분하고, Haiku 5.5의 입력 길이별 가격을 적용합니다. 오래된 모델의 불명확한 긴 컨텍스트 요청은 추정하지 않습니다. 현재 정가 비교이므로 과거 청구서와 일치하지 않습니다. 서비스 등급·지역·할인·구독·크레딧·세금·도구·멀티모달 비용·기록되지 않은 캐시 쓰기 가산액은 실제 금액을 바꿀 수 있습니다. OpenCode 기록 비용은 다른 시점의 가격표일 수 있습니다. 서로 다른 클라이언트로 가져온 같은 요청은 공통 식별자가 없으면 중복 제거할 수 없습니다.

## 개인정보·조회 제한

사용량 숫자, 길이가 제한된 모델·서비스 ID, 임시 중복 제거 ID만 메모리에 남깁니다. JSONL 원문은 사용량 필드를 얻기 위해 일시적으로 해석한 뒤 버리고 별도 파일에 저장하거나 전송하지 않습니다. SQL 결과에는 사용량 필드만 포함합니다. 자격증명·키체인·API 조회·로그 업로드를 사용하지 않습니다.

JSONL 클라이언트별 256 MiB·10,000파일·15초, 전체 100,000개 사용량 ID로 제한하며 2 MiB보다 긴 행은 건너뜁니다. OpenCode는 쿼리당 50,000행·16 MiB·3초, 최대 16개 DB이며 DB 사이에서 20초 제한을 확인합니다. 읽지 못하거나 잘린 기록·지원되지 않는 형식·조회 상한은 **일부 기록만 조회됨**으로 표시합니다. 매우 큰 기록에서는 소계만 보일 수 있습니다. 기본 폴더가 없다는 것은 해당 로컬 기록이 없다는 뜻이지 계정 비용이 0달러라는 뜻이 아닙니다.
